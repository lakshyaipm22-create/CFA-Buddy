# Analytics and study intelligence layer for CFA Buddy (v2)

This change adds five interconnected analysis features to the question-bank system: error classification with confidence calibration, time analysis with difficulty progression tracking, spaced repetition for weak questions, progress timeline with target comparison, and a smart session recommendation engine. The utility-first architecture uses pure-function modules, React component layers consuming localStorage via `useState` lazy initializers, and 234 passing tests across 8 new test files.

All six concerns from the v1 review have been addressed: gap analysis looks up `moduleResult.moduleName` first with subject fallback, `useMemo` replaced with `useEffect` in attempt-review, cross-feature imports re-routed through `src/shared/analytics/` barrel, `try/catch` wraps the spaced-rep loop in `saveAttempt`, MAX_QUEUE_SIZE=200 caps the repetition queue, and `SmartSessionCard` uses `window.location.reload()` when already on `/questions`.

Watch for: dead `getAttempts` import in insights-content (confirmed). Cross-feature import from question-bank to practice for annotations-storage is not routed through shared (confirmed). Spaced-rep eviction comment/code mismatch on strategy description (confirmed, cosmetic).

**Verdict**: APPROVED

## High-level view

The shared barrel at `src/shared/analytics/index.ts` re-exports four components, one utility, and two types from question-bank. The insights page consumes only through this barrel, but the `getAttempts` import is present and unused — the component reads localStorage directly in a `useState` lazy initializer instead.

The `attempt-review.tsx` introduces a new cross-feature import to `@/features/practice/utils/annotations-storage` for note management. This follows the same pattern as the pre-existing `search` -> `practice` import but was not extracted to shared — an inconsistency with the barrel approach used for analytics.

## Annotations cross-feature import

The v1 fix extracted question-bank components/utilities into `src/shared/analytics/` so insights could consume them without a direct cross-feature import. However, `attempt-review.tsx` introduces a new cross-feature path:

```typescript
import { getNotes, saveNote, deleteNote } from '@/features/practice/utils/annotations-storage';
```

This crosses from `question-bank` into `practice`. The same pattern already exists in `src/features/search/components/search-modal.tsx`, so the codebase is inconsistent — some cross-feature imports go through shared, others don't. For notes/annotations specifically, extracting to `src/shared/annotations/` would formalize the dependency.

## Eviction strategy comment mismatch

```typescript
// Enforce max queue size: drop the oldest item (furthest due date already passed)
if (queue.length >= MAX_QUEUE_SIZE) {
  // Remove the item with the longest interval (most advanced, closest to mastery)
  const maxIntervalIdx = queue.reduce((maxIdx, item, idx, arr) =>
    item.interval > arr[maxIdx].interval ? idx : maxIdx, 0);
  queue.splice(maxIntervalIdx, 1);
}
```

The outer comment says "drop the oldest item (furthest due date already passed)" — suggesting time-based eviction. The inner comment and code correctly evict by longest interval (closest to mastery). The outer comment should be updated to match.
