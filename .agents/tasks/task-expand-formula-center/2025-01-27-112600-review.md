# Formula Center expansion to 132 formulas with tabbed navigation

The formula database grows from 29 entries to 132, covering all 10 CFA Level I subjects with new metadata fields (topic, difficulty, examFrequency, keyTip). The UI is completely redesigned around subject tabs, collapsible topic groups, expandable formula cards, and three view modes (All, Quick Reference, Bookmarked). A separate subject-metadata.ts file provides curriculum structure (modules, key topics, exam weights, topic groupings) for each subject, though it is currently unused by any component.

Watch for: subject-metadata.ts is dead code (confirmed); Quick Reference mode shows 90/132 formulas — 68% — which limits its utility as a filter (confirmed); the ~55KB formula seed ships entirely client-side with no code-splitting boundary (confirmed).

**Verdict**: APPROVED

## High-level view

The formula data expansion covers 132 unique IDs across all 10 subjects, preserving existing IDs for bookmark compatibility. The data is the biggest client-side payload change at ~55KB, delivered as a single inline array with no dynamic import boundary.

The UI redesign replaces a flat card list with a three-tier navigation hierarchy (view mode > subject tab > topic group > expandable card). The component is 571 lines as a single file with four helper sub-components defined inline.

The subject-metadata module defines comprehensive curriculum metadata but is never imported anywhere — 297 lines of data that will drift from the formula seed's actual topic values without consumer or test coverage.

The Quick Reference filter selects `examFrequency === 'high'`, but 90 of 132 formulas carry that label, making the filter a weak discriminator. A user seeking their top 20-30 formulas still has most of the list to wade through.

## Dead subject-metadata module

`src/features/formulas/data/subject-metadata.ts` exports `SUBJECT_METADATA` — a Record containing modules, keyTopics, examWeight, and topicGroups for all 10 subjects. No file in the codebase imports it. Tree-shaking should eliminate it from the production bundle, but the data will drift from the actual formula seed topics without a consumer or test enforcing alignment.

The `topicGroups` field overlaps with but does not exactly match the `topic` values in formula-seed.ts. Economics metadata lists "International Trade" as a topic group, but no formula in the seed uses that topic. Anyone who tries to use `topicGroups` for navigation logic will encounter mismatches.

## Quick Reference mode discriminating power

The frequency distribution is 90 high, 41 medium, 2 low. With only 1.5% of formulas marked low-frequency, the labeling reads as "everything is important" rather than a genuine triage of exam priority. The frequency badge (green/gold/gray dot) on each card also loses visual utility when nearly every card has the same green dot.

## Subject tab count asymmetry

`SUBJECT_COUNTS` is computed once at module load from the full unfiltered seed. The "All" tab uses `filteredFormulas.length`, which respects the active view mode. When a user is in Quick Reference mode looking at 90 formulas total, the subject tabs still say "Quant (24)", "FSA (22)", etc. Clicking "FSA (22)" then shows only the high-frequency FSA formulas (likely fewer than 22), creating a count/content mismatch that makes users doubt the filter is working.

## Expand All/Collapse All during active search

The `effectiveExpandedTopics` memo overrides `expandedTopics` when `searchQuery.length >= 2`, forcing all groups open. The "Collapse All" button calls `setExpandedTopics(new Set())`, but this underlying state is invisible while search auto-expansion is active. The button remains visible and clickable but does nothing — a confusing dead control.

## Bookmarked-first sorting removed

The old component sorted bookmarked formulas to the top of the flat list. The new component removes this in favor of the "Bookmarked" view mode tab. Users who relied on bookmarked formulas floating to the top in the default view now need to explicitly switch tabs. This is a behavioral change for anyone with existing bookmarks.
